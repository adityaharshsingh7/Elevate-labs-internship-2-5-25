
KNN Classification using scikit-learn

This project showcases the application of the K-Nearest Neighbors (KNN) classification algorithm using the scikit-learn library. It covers the complete workflow from data preprocessing to model evaluation, including experimenting with different values of k and analyzing performance using accuracy metrics and confusion matrices.

Key steps followed:

 Utilized the Iris dataset, a well-known dataset for classification tasks.
 Explored the dataset's structure and verified that there were no missing values.
 Created basic visualizations to understand the distribution of the features.
 Split the dataset into training and testing subsets.
 Trained the KNN model on the training set, varying the number of neighbors from 1 to 10 in a loop.
 Assessed model performance for each value of k and plotted training and testing accuracy.
 Generated confusion matrices to evaluate predictions across the three Iris species.
